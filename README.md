# Проект «Сложно сосредоточиться»

** Ссылка на проект:**

https://github.com/Yulia-Pospelova/slozhno-sosredotochitsya-fd

Учебный проект: адаптивная вёрстка лендинга с переключением цветовых тем и акцентом на accessibility.

## Описание

Проект представляет собой лендинг о проблемах концентрации внимания и способах её улучшения.

Страница включает:

- шапку с переключением тем;
- несколько контентных секций;
- адаптивную галерею изображений;
- декоративные элементы интерфейса;
- футер с крупным типографическим акцентом.

## Технологии

- HTML5
- CSS3
- Flexbox
- Grid Layout
- CSS Variables
- Media Queries
- clamp()
- БЭМ
- Адаптивная вёрстка
- Responsive images
- WebP
- Accessibility
- JavaScript

## Что реализовано

- семантическая HTML-структура;
- переключение тем: dark / light / auto;
- поддержка системной темы через prefers-color-scheme;
- адаптация под mobile, tablet и desktop;
- fluid-типографика через clamp();
- responsive-изображения через picture, source, srcset, sizes;
- поддержка WebP и JPG fallback;
- доступные состояния интерактивных элементов;
- навигация с клавиатуры;
- проверка со screen reader;
- декоративные элементы через псевдоэлементы.

## Адаптивность

Проект адаптирован для нескольких контрольных ширин:

- 375px — мобильная версия;
- 768px — планшетная версия;
- 1024px — desktop-версия.
